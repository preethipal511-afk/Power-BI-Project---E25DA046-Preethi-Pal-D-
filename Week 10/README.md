# Week 10 – Real Estate Analytics Dashboard

## Project Overview
This project focuses on analyzing real estate sales data using Microsoft Power BI. An interactive dashboard was developed to understand house prices, property features, and geographical distribution in King County.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

## Dataset
**Dataset Name:** King County House Sales Dataset (`kc_house_data.csv`)

The dataset contains information about house sales, including:
- House prices
- Number of bedrooms and bathrooms
- Living area and lot size
- Waterfront availability
- Property grade and condition
- Latitude and longitude

## Key Performance Indicators (KPIs)
1. Total Properties Sold
2. Average House Price
3. Median House Price
4. Average Living Area
5. Average Price per SqFt

## Dashboard Visualizations
- Average House Price by Bedrooms
- Average House Price by Bathrooms
- Average House Price by Waterfront
- Average House Price by Grade
- Average House Price by Condition
- Property Location Map

## Interactive Filters
- House Price
- Living Area (Sq Ft)

## Key Insights
- Analyzed house price variations based on bedrooms and bathrooms.
- Compared property prices based on waterfront availability.
- Examined the relationship between property grade, condition, and house prices.
- Explored geographical distribution of properties.
- Evaluated overall property sales and average pricing.

## Learning Outcomes
- Creating interactive dashboards using Power BI.
- Writing DAX measures for data analysis.
- Working with different data visualizations.
- Using slicers and filters for interactive analysis.
- Presenting real estate data through meaningful insights.

## Project Files
- `Week10_Real_Estate_Analytics.pbix` – Power BI dashboard file.
