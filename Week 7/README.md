# Week 7 – Student Performance Data Cleaning & Transformation

## Objective
Clean and transform the Student Performance in Exams dataset using Power BI.

## Tasks Completed
- Imported the Student Performance dataset
- Cleaned and transformed the data
- Removed duplicates and invalid rows
- Standardized categorical values
- Created Total Score
- Created Average Score
- Created Performance Grade
- Created Pass/Fail classification
- Unpivoted Math, Reading and Writing scores
- Created Student Base table
- Created Students Details table
- Created Students Marks table
- Created one-to-many relationship using Student ID
- Created DAX measures

## DAX Measures
- Average Math Score
- Average Reading Score
- Average Writing Score
- Overall Average Score
- Overall Pass %

## Tools Used
- Power BI Desktop
- Power Query
- DAX

## Output
A cleaned and structured Student Performance dataset ready for dashboard development in Week 8.
