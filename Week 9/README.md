# Week 9: Housing Data Cleaning and Transformation

## Project Overview
This project focuses on cleaning and transforming the King County housing dataset using Microsoft Power BI and Power Query.

## Dataset
- **File:** `kc_house_data.csv`
- **Description:** Housing sales data containing property prices, living area, bedrooms, bathrooms, construction year, renovation year, and sale dates.

## Tasks Completed
- Imported the housing dataset into Power Query.
- Checked missing values and data errors.
- Filtered properties with zero bedrooms or bathrooms.
- Converted the sale date into a proper date format.
- Created Sale Year and Sale Month columns.
- Calculated Property Age at Sale.
- Calculated Price per SqFt.
- Created a Total Area column.
- Created an Is Renovated column.
- Categorized properties by size: Small, Medium, Large, and Luxury.
- Categorized properties by price: Budget, Affordable, Premium, and Luxury.

## Tools Used
- Microsoft Power BI
- Power Query
- Power Query M

## Project Files
- `Week9_Housing_Data.pbix` — Power BI project containing the data cleaning and transformation steps.
- `kc_house_data.csv` — Original housing dataset.

## Outcome
The dataset was cleaned and transformed to support further housing data analysis in Power BI.
